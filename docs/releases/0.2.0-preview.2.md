# Pinyon Shift 0.2.0-preview.2

The launcher now prepares graphics automatically before play, including for
existing installations. No shader-generation commands or developer caches are
required. Preparation runs locally, hidden and muted, using your verified game
files and separate temporary states. Your save is not copied or reset.

Valid artifacts are reused. Missing or damaged files are repaired automatically;
renderer, driver and resolution changes trigger preparation again. Reopen the
launcher to retry an interrupted preparation.

This preview also includes additional retail shader variants and corrects
startup catalog handling for the native velocity pass. CI checks the source
boundary, tooling, launcher build, behavior and release package.

Local startup checks do not establish complete gameplay coverage. New scenes,
long sessions, other GPUs and resolution scales still need qualification, so
this remains a preview. Stable downloads remain unchanged.

Download **PinyonShift-Launcher.zip**, keep its included files together, and use
your personally dumped supported disc. The package contains public source and
the launcher; game content and shaders are generated only on your computer.
