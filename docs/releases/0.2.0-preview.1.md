# Pinyon Shift 0.2.0-preview.1

Prerelease for validating the 0.2.0 launcher and renderer changes before stable
promotion. Existing stable downloads remain available.

**Known blocker: fresh installations can render a black screen.** Local
empty-state startup reproduced missing offline shader-analysis records. Setup
does not yet produce the required artifacts. This preview is not recommended
for a first installation and must not be promoted to stable in this state.

## Changes

- Choose and remember a local installation folder from the packaged launcher.
  Existing installations and saves stay in place; environment overrides remain
  supported.
- Include missing CMake source inputs in the launcher payload and resolve SDK
  paths correctly for packaged installations.
- Provision compatible CMake and preserve the underlying configure/compiler
  errors in setup logs.
- Fix renderer fence-wait error handling, cancellation and startup prewarm worker
  limits and selection.
- Retain bounded reflection-mipmap and geometry-cache improvements, and
  consolidate obsolete renderer research documentation.
- Verify launcher behavior in CI, and handle Windows short/long path aliases in
  toolchain regression tests.

## Validation and limitations

CI checks the public source boundary, tooling tests, launcher build and launcher
behavior. It cannot test the game without a personally dumped supported disc and
a local GPU. Local game and clean-install verification are separate release gates.

This preview requires completion of the first-install shader artifact workflow
before stable promotion. Existing developer caches do not prove
that a fresh installation is playable. Renderer coverage and performance vary by
scene; AMD/Intel hardware, all resolution scales and long-play behavior are not
qualified by a local NVIDIA smoke test.

Download **PinyonShift-Launcher.zip**, keep both included files together, and use
your personally dumped supported disc. The download contains the launcher and
public source, not game files, generated game code or a compiled game executable.
