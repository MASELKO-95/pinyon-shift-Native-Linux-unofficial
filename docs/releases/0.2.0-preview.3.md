# Pinyon Shift 0.2.0-preview.3

Fix launcher readiness for existing installations. An old executable no longer
enables Play when the extracted game files are missing or the build belongs to
an earlier source payload. The launcher asks you to select your disc image and
run setup to restore or update the installation. Saves stay in place.

Automatic shader preparation from preview.2 is retained. CI exercises missing
game files, outdated builds, matching builds and graphics preparation progress.
This remains a preview pending broader gameplay qualification.
